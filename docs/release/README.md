# MaaSVWB

《影之诗：超凡世界》安卓模拟器自动操作工具，基于 MaaFramework 开发。

目前提供以下功能：

- 按人工录入的固定解法完成盘面解密；
- 自动完成已支持的对战教程；
- 自动识别并跳过教程对话和说明弹窗；
- 按手牌和随从序号执行出牌、攻击、进化、护符启动及指定目标等操作。

当前提供以下盘面解密脚本：

- 同时学习【守护】【突进】【疾驰】吧！；
- 学习／熟练运用巴巴洛丝皇家护卫吧！；
- 学习／熟练运用护符主教吧！。

开局换牌目前支持直接确认，暂不支持自动选择需要替换的卡牌。

## 使用前准备

1. 将压缩包完整解压到一个可写目录，不要只把 EXE 单独复制出来。
2. 启动安卓模拟器并开启 ADB 调试。
3. 将模拟器分辨率设为横屏 `1280 × 720`。
4. 启动 `MaaSVWB.exe`。
5. 在“设置”页刷新设备；自动发现失败时，填写模拟器的 ADB 路径和设备序列号。
6. 使用“测试连接”确认程序可以获取模拟器画面。

## 执行任务

### 盘面解密

进入游戏的盘面解密列表，然后在软件中选择：

- “自动完成所有未完成的解密”；或
- “选择盘面解密”，再选择类别和具体关卡。

点击“开始执行”后，程序会自动定位关卡、进入盘面并执行已录入解法。灰色关卡表示
当前版本尚未提供对应脚本。

### 对战教程

进入游戏的对战教程列表，选择运行方式和具体教程后开始执行。教程中的对话与说明
弹窗会由程序自动处理，不需要额外设置。

“地域试炼”功能目前尚未开放。

## 注意事项

- 自动操作期间请勿手动点击或拖动模拟器画面。
- 请保持游戏为横屏 `1280 × 720`；其他分辨率当前不受支持。
- 如果任务失败，可在软件中查看运行日志；详细日志和识别截图位于程序目录下的
  `debug/` 文件夹。
- 用户设置保存在 `%APPDATA%\MaaSVWB\settings.json`。
- 更新版本时请完整解压新压缩包，避免新旧文件混用。
